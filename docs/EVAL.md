## Method

1. A fresh Postgres + pgvector container is started and the three sample documents are ingested (page-bounded chunks, embedded with Gemini).
2. For each question, the same question embedding is used for three searches: hybrid (the production path), vector only and keyword only. Each is scored against the expected pages.
3. The question is then sent through the full `/ask` pipeline. An answer counts when it is answered, cites at least one expected page, and (separately) contains the expected facts.
4. Unanswerable questions count when SpecLens refuses.
5. Model output can vary slightly between runs; retrieval numbers are deterministic for a given embedding model.
